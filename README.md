# QuickChat Application – Part 3

## 1. Project Overview

QuickChat is a Java-based messaging application developed using NetBeans IDE. The application allows users to register, log in, send messages and manage stored messages.

Part 3 builds on the work completed in Part 1 and Part 2. It introduces arrays, string manipulation, JSON file storage and message reporting.

## 2. Project Objectives

The objectives of Part 3 are to:

- Store and manage messages using arrays.
- Generate unique message IDs.
- Create message hashes.
- Store messages in a JSON file.
- Retrieve previously stored messages.
- Display stored messages.
- Generate a message report.
- Perform automated unit testing.

## 3. Technologies Used

- Java programming language.
- NetBeans IDE.
- JUnit testing framework.
- JSON-simple library.
- GitHub for version control.

## 4. Project Classes

| Class | Description |
|---|---|
| Main.java | Runs the QuickChat application. |
| Login.java | Handles registration and login. |
| Message.java | Creates and manages messages. |
| ChatApp.java | Controls the messaging application and menu options. |
| MessageTest.java | Tests message functionality. |

## 5. Part 3 Features

### Message Management
The application manages different message categories:

- Sent messages.
- Disregarded messages.
- Stored messages.

### Message Identification
Each message receives a unique message ID.

### Message Hash
A message hash is generated to help identify messages.

### JSON Storage
Messages are stored in a JSON file and can be retrieved when required.

### Stored Messages
A new menu option allows users to view previously stored messages.

### Message Report
The application generates a report showing message information.

## 6. Main Menu

The application provides options for users to:

1. Send a message.
2. View message information.
3. Display message reports.
4. View stored messages.
5. Quit the application.

## 7. Testing

JUnit is used to test the application and check that its features work correctly.

Testing includes:
- Message ID generation.
- Message hash generation.
- Message storage.
- Message retrieval.
- Message reporting.
- Array functionality.

## 8. How to Run the Application

1. Open NetBeans IDE.
2. Open the QuickChatPart2 project.
3. Check that all Java classes and libraries are included.
4. Right-click the project.
5. Select Clean and Build.
6. Check that the build is successful.
7. Run the application.
8. Follow the menu instructions.

## 9. GitHub Version Control

GitHub is used to save the project and track development progress.

Meaningful commits are made when new features are added or existing code is improved.
